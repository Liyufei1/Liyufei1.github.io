OpenGL学习随笔-GLFW

使用 GLFW 创建 OpenGL 窗口、处理输入并完成基础渲染循环

2026-01-06
阅读时长: 5 分钟

GLFW

GLFW 是一个轻量、跨平台的窗口与输入库，常用于 OpenGL 项目中创建窗口、管理上下文和处理输入。它本身不负责渲染，而是为 OpenGL 提供运行环境。

在实际开发中，GLFW 负责窗口与输入，GLAD 负责加载 OpenGL 函数指针。简单来说，GLFW 解决的是与操作系统交互的问题，OpenGL 解决的是图形绘制的问题。

主要特性

  • 跨平台：支持 Windows、macOS、Linux 等平台
  • 专注图形开发：面向 OpenGL / Vulkan 场景设计，功能聚焦
  • 窗口管理简单：可以快速完成窗口创建、销毁、尺寸调整等操作
  • 输入接口统一：键盘、鼠标、滚轮、手柄等输入处理方式一致
  • 事件回调机制清晰：窗口变化、鼠标移动、滚轮滚动等都可以通过回调处理
  • 适合学习 OpenGL：API 设计直观，适合作为入门阶段的窗口库

和 GLUT 相比，GLFW 更现代、可控性更高；和 SDL 相比，GLFW 更轻量，也更聚焦于图形上下文与输入管理。

基本使用流程

通常可以把 GLFW 的使用流程概括为下面几步：

  1. 初始化 GLFW
  2. 指定 OpenGL 版本与上下文配置
  3. 创建窗口
  4. 绑定当前上下文
  5. 初始化 GLAD
  6. 设置视口与回调函数
  7. 进入渲染循环
  8. 退出前释放资源

这个流程非常重要，因为顺序一般不能随意打乱。比如：

  • 没有先创建上下文，就无法正确初始化 GLAD
  • 没有设置当前上下文，后续 OpenGL 调用可能无效
  • 没有在循环中调用 glfwPollEvents()，窗口输入和系统事件就不会及时更新

#include <glad/glad.h>
#include <GLFW/glfw3.h>	

//初始化GLFW
glfwInit();

//设置主要和次要版本,本文档使用3.3版本OpenGL的核心模式
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR,3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR,3);
glfwWindowHint(GLFW_OPENGL_PROFILE,GLFW_OPENGL_CORE_PROFILE);

//新建一个窗口
GLFWwindow * MyWindows = glfwCreateWindow(800,600,"Title",NULL,NULL);
if (MyWindows == NULL){
    std::cout << "Create Windows Failed!" << std::endl;
    glfwTerminate();
    return -1;
}
//创建上下文关联
glfwMakeContextCurrent(MyWindows);

//初始化GLAD，用于管理OpenGL的函数指针
if (!gladLoadGLLoader((GLADloadproc)glfwGetProcAddress)){
    std::cout << "Failed to initiallize GLAD " << std::endl;
    return -1;
}

//设置视口,左下角位置为(0,0),宽800，高600
glViewport(0,0,800,600);
glEnable(GL_PROGRAM_POINT_SIZE);

//注册监听
glfwSetFramebufferSizeCallback(MyWindows,FrameBufferSizeCallback);//监听函数（1）定义在下方
    //渲染循环
while (!glfwWindowShouldClose(MyWindows)){
    //~Input Begin
    ProcessInput(MyWindows);//输入函数（2）
    //~Input End

    //~Render command Begin
    glClearColor(0.4f,0.9f,0.8f,1.0f);
    glClear(GL_COLOR_BUFFER_BIT);
    //~Render command End


    //检查并调用事件，交换缓冲
    glfwSwapBuffers(MyWindows);//采用双缓存机制，保证帧与帧之间不会闪烁
    glfwPollEvents();//检测事件输入：键盘输入、鼠标点击、Window缩放等,并更新Window
}


glfwTerminate();//释放/删除 分配的资源

void ProcessInput(GLFWwindow* Window)

常用函数

下面列出学习阶段最常见的一组 GLFW 接口。

函数 作用
glfwInit() 初始化 GLFW。几乎所有 GLFW 调用都要在它之后进行
glfwWindowHint() 设置窗口属性或上下文版本，例如指定 OpenGL 3.3 Core Profile
glfwCreateWindow() 创建窗口和对应的 OpenGL 上下文
glfwMakeContextCurrent() 将某个窗口的上下文设为当前上下文
glfwSetFramebufferSizeCallback() 注册帧缓冲大小变化回调，窗口尺寸变化时通常要更新视口
glfwWindowShouldClose() 判断窗口是否需要关闭，常用于主循环退出条件
glfwSetWindowShouldClose() 主动设置窗口关闭状态
glfwGetKey() 读取键盘按键状态
glfwPollEvents() 处理当前帧积累的输入和窗口事件
glfwSwapBuffers() 交换前后缓冲区，把当前渲染结果显示出来
glfwTerminate() 释放 GLFW 相关资源，程序退出前调用
glfwGetTime() 获取时间，适合做动画、计时和帧间隔计算

补充说明

  1. glfwWindowHint() 的作用

这组接口用于在创建窗口前告诉 GLFW：你希望得到一个什么样的 OpenGL 环境。比如下面这三行：

1
2
3

glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);

它们表示：

  • 使用 OpenGL 3.3
  • 使用 Core Profile
  • 只启用现代 OpenGL 的核心功能

如果你学习的是 LearnOpenGL 一类教程，这样的配置非常常见。

  1. 为什么要设置视口回调

窗口大小变化后，OpenGL 默认不会自动帮你更新视口范围，因此通常需要注册：

1

glfwSetFramebufferSizeCallback(window, framebufferSizeCallback);

对应的回调函数里重新调用：

1

glViewport(0, 0, width, height);

这样窗口尺寸变化后，绘制区域才能和新的窗口大小保持一致。

  1. glfwSwapBuffers() 和 glfwPollEvents()

渲染循环里最常见的两行就是：

1
2

glfwSwapBuffers(window);
glfwPollEvents();

它们的职责分别是：

  • glfwSwapBuffers(window)：把当前帧的结果显示到屏幕上
  • glfwPollEvents()：处理键盘、鼠标、窗口消息等事件

如果少了前者，画面不会正常更新；如果少了后者，窗口就可能出现“无响应”现象。

  1. 一个常见搭配：GLFW + GLAD

很多初学者会把 GLFW 和 GLAD 的职责混在一起。实际上两者分工非常明确：

  • GLFW 负责“创建环境”
  • GLAD 负责“加载 OpenGL 函数”

只有窗口和上下文准备完成后，GLAD 才能拿到正确的 OpenGL 函数地址。因此一般顺序一定是：

  1. glfwCreateWindow()
  2. glfwMakeContextCurrent()
  3. gladLoadGLLoader(...)

小结

GLFW 本身并不复杂，但它在 OpenGL 项目里承担的是非常基础的一层：窗口、上下文、输入和事件循环几乎都离不开它。学习阶段只要先掌握下面这几个点，后续就能比较顺利地进入顶点、着色器、纹理和坐标变换等内容：

  • 会创建一个基本窗口
  • 理解上下文与 GLAD 初始化顺序
  • 能处理窗口缩放回调
  • 能在主循环里处理输入和交换缓冲
