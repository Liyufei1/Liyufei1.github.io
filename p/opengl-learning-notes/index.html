OpenGL 坐标与视口

OpenGL 最终会把经过变换后的顶点映射到屏幕空间，而 glViewport() 决定了标准化设备坐标（NDC）如何映射到窗口中的像素区域。

例如：

  • NDC 的坐标范围通常在 [-1, 1]
  • glViewport(0, 0, 800, 600) 表示把结果映射到窗口左下角起始、宽 800、高 600 的区域

因此，像 (-0.5, 0.5) 这样的坐标，经过视口变换之后，就会落到屏幕中的某个具体像素位置。

缓冲区对象

OpenGL 不会直接从普通 C++ 数组里长期读取顶点数据，而是通常先把数据上传到 GPU 缓冲区中。最常见的是顶点缓冲对象 VBO。

一个最基础的例子如下：

1
2
3
4

unsigned int vbo;
glGenBuffers(1, &vbo);
glBindBuffer(GL_ARRAY_BUFFER, vbo);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);

这三步分别表示：

  • 创建一个缓冲区对象 ID
  • 绑定到 GL_ARRAY_BUFFER
  • 把顶点数据上传到当前绑定的缓冲区

glGenBuffers 

1

void glGenBuffers(GLsizei n, GLuint *buffers);

作用：生成一个或多个缓冲区对象名称（ID）。

要点：

  • 只生成对象名，不分配实际 GPU 存储
  • 通常需要和 glBindBuffer、glBufferData 配合使用

glBindBuffer 

1

void glBindBuffer(GLenum target, GLuint buffer);

作用：把某个缓冲区对象绑定到指定目标。

常见目标：

  • GL_ARRAY_BUFFER：顶点数据
  • GL_ELEMENT_ARRAY_BUFFER：索引数据
  • GL_UNIFORM_BUFFER：统一变量缓冲区

glBufferData 

1

void glBufferData(GLenum target, GLsizeiptr size, const void *data, GLenum usage);

作用：为当前绑定的缓冲区分配存储并上传数据。

常见 usage：

  • GL_STATIC_DRAW：数据很少变化
  • GL_DYNAMIC_DRAW：数据会频繁修改
  • GL_STREAM_DRAW：数据基本每帧更新

示例：

1

glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);

着色器

着色器（Shader）是运行在 GPU 上的小程序。入门阶段最常见的是：

  • 顶点着色器（Vertex Shader）
  • 片段着色器（Fragment Shader）

一个典型流程包括：

  1. 创建着色器对象
  2. 传入源码
  3. 编译着色器
  4. 检查编译结果

示例：

unsigned int vertexShader = glCreateShader(GL_VERTEX_SHADER);
glShaderSource(vertexShader, 1, &vertexShaderSource, nullptr);
glCompileShader(vertexShader);

GLint success;
glGetShaderiv(vertexShader, GL_COMPILE_STATUS, &success);
if (!success)
{
    char infoLog[512];
    glGetShaderInfoLog(vertexShader, 512, nullptr, infoLog);
    printf("Shader compilation failed:\n%s\n", infoLog);
}

作用：创建一个指定类型的着色器对象。

常见类型：

  • GL_VERTEX_SHADER
  • GL_FRAGMENT_SHADER
  • GL_GEOMETRY_SHADER
  • GL_COMPUTE_SHADER

着色器程序

单个着色器只能完成渲染管线中的一个阶段，真正参与绘制的是“着色器程序对象（Program）”。它负责把多个着色器链接成一个整体。

典型流程如下：

glAttachShader(shaderProgram, vertexShader);

glLinkProgram(shaderProgram);

glGetProgramiv(shaderProgram, GL_LINK_STATUS, &success);
if (!success)
{
    char infoLog[512];
    glGetProgramInfoLog(shaderProgram, 512, nullptr, infoLog);
}

glUseProgram(shaderProgram);
glDeleteShader(vertexShader);
glDeleteShader(fragmentShader);

顶点输入与 VAO/VBO/EBO

OpenGL 需要知道：

  • 顶点数据放在哪里
  • 每个顶点由哪些属性组成
  • 每个属性如何解释

这部分通常由 VAO、VBO 和 EBO 共同完成：

  • VBO：保存顶点数据
  • EBO：保存索引数据
  • VAO：记录顶点属性布局和相关绑定状态

示例：

glGenVertexArrays(1, &vao);

glBindVertexArray(vao);

glBindBuffer(GL_ARRAY_BUFFER, vbo);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);

glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);
glEnableVertexAttribArray(0);

glBindBuffer(GL_ARRAY_BUFFER, 0);
glBindVertexArray(0);

glVertexAttribPointer 

1
2

void glVertexAttribPointer(GLuint index, GLint size, GLenum type, GLboolean normalized,
                           GLsizei stride, const void *pointer);

作用：定义某个顶点属性在当前顶点缓冲中的布局。

例如：

1

glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3 * sizeof(float), (void*)0);

可以理解为：

  • 位置属性绑定到 location = 0
  • 每个顶点读 3 个 float
  • 顶点之间步长是 3 * sizeof(float)
  • 从当前缓冲区偏移 0 的位置开始读

glEnableVertexAttribArray 

1

void glEnableVertexAttribArray(GLuint index);

作用：启用某个顶点属性通道。

void glGenVertexArrays(GLsizei n, GLuint *arrays);

作用：生成一个或多个 VAO 对象。

glBindVertexArray 

1

void glBindVertexArray(GLuint array);

作用：绑定一个 VAO，使之后的顶点输入配置记录到它里面。

glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);

glEnableVertexAttribArray(0);

glDrawElements 

1

void glDrawElements(GLenum mode, GLsizei count, GLenum type, const void *indices);

作用：根据索引缓冲里的索引顺序绘制图元。

常见参数：

  • GL_TRIANGLES：按三角形绘制
  • count：索引个数
  • GL_UNSIGNED_INT：索引类型
  • indices：当使用 EBO 时通常传 0，表示从索引缓冲开头读取

Uniform 设置

OpenGL 中很多参数是通过 uniform 传给着色器的，例如颜色、矩阵、光照参数等。

常见接口有：

  • glUniform1f：设置单个浮点数
  • glUniform3f：设置三个浮点数
  • glUniform3fv：设置浮点向量数组或单个 vec3
  • glUniform1i：设置整型值，常用于纹理采样器绑定

GLM 库

GLM（OpenGL Mathematics）是一个专门为 OpenGL 设计的 C++ 数学库，提供了与 GLSL 风格接近的向量、矩阵和变换函数。

主要用途包括：

  • vec2、vec3、vec4 等向量类型
  • mat3、mat4 等矩阵类型
  • 点积、叉积、归一化等常见数学运算
  • 平移、旋转、缩放、透视投影等变换构造

STB 库

STB 是一组轻量级的单文件 C/C++ 工具库。在 OpenGL 入门中，最常见的是 stb_image，用于读取图片数据。

stb_image

最常用接口：

1
2

int width, height, nrChannels;
unsigned char* data = stbi_load("container.jpg", &width, &height, &nrChannels, 0);

作用：从磁盘加载图片，并返回原始像素数据，便于之后用 glTexImage2D 上传到 GPU。

小结

这篇内容主要覆盖了 OpenGL 入门阶段最常接触的一批基础接口。学习时可以重点抓住下面这条主线：

  • 用 VBO/EBO 把顶点与索引数据上传到 GPU
  • 用 Shader 和 Program 建立可执行的渲染逻辑
  • 用 VAO 记录顶点属性布局
  • 用 glDrawElements 或 glDrawArrays 发起绘制
  • 用纹理把图像数据引入到着色器计算中

如果把这些部分连起来，你就已经拥有了一个最基础的现代 OpenGL 渲染流程。
