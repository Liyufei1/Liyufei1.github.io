GLSL学习笔记

GLSL（OpenGL Shading Language）是 OpenGL 使用的着色器语言，用于在 GPU 上编写可编程的渲染逻辑。学习 OpenGL 时，GLSL 是绕不开的一部分，因为顶点变换、颜色计算、光照、纹理采样等过程，通常都要通过着色器来完成。

在现代 OpenGL 中，最常接触的是两类着色器：

  • Vertex Shader（顶点着色器）：处理顶点数据，例如顶点位置、法线、纹理坐标等
  • Fragment Shader（片段着色器）：处理像素颜色输出，例如颜色混合、纹理采样、光照结果等

本文主要记录 GLSL 的基础结构、常用关键字、常见数据类型以及一些常用函数。

GLSL 的基本组成

在 OpenGL 的基础渲染流程中，GLSL 最常见的组成部分是：

  • 顶点着色器（Vertex Shader）
  • 片段着色器（Fragment Shader）

如果只写最基础的三角形示例，这两个阶段通常就够用了。

可以简单理解为：

  • 顶点着色器决定“顶点如何被处理”
  • 片段着色器决定“像素最终显示什么颜色”

一个最简单的示例

下面是一组最基础的 GLSL 示例，用于把顶点位置直接输出到裁剪空间，并在片段着色器中输出固定颜色。

const char* vertexShaderSource = "#version 330 core\n"
    "layout (location = 0) in vec3 aPos;\n"
    "void main()\n"
    "{\n"
    "    gl_Position = vec4(aPos, 1.0);\n"
    "    gl_PointSize = 20.0;\n"
    "}\0";

const char* fragmentShaderSource = "#version 330 core\n"
    "out vec4 FragColor;\n"
    "void main()\n"
    "{\n"
    "    FragColor = vec4(1.0, 0.5, 0.2, 1.0);\n"
    "}\0";

这段代码里：

  • aPos 是从顶点缓冲传入的顶点坐标
  • gl_Position 是顶点着色器必须写入的重要输出变量
  • FragColor 是片段着色器输出的最终颜色
  • gl_PointSize 用于设置点图元的大小，仅在绘制点时生效

常用关键字

关键字 说明 示例
in 当前着色器的输入变量 layout (location = 0) in vec3 aPos;
out 当前着色器的输出变量 out vec4 FragColor;
uniform 由 CPU 传入、在同一次绘制调用中保持一致的全局变量 uniform mat4 model;
layout 指定变量的布局信息，例如顶点属性位置 layout (location = 1) in vec3 aNormal;
attribute 旧版 GLSL 中的顶点输入关键字，现代 GLSL 中通常使用 in 替代 attribute vec3 aPos;
varying 旧版 GLSL 中用于阶段间传递数据，现代 GLSL 中使用 out 和 in 替代 varying vec2 TexCoord;

需要注意：

  • attribute 和 varying 常见于旧版 OpenGL / OpenGL ES 教程
  • 在现代 OpenGL（如 #version 330 core）中，更常见的是 in 和 out
  • 顶点着色器的 out，会作为片段着色器的 in

例如：

// Vertex Shader
out vec3 ourColor;

// Fragment Shader
in vec3 ourColor;

常见数据类型

GLSL 的数据类型和 C 语言有些相似，但也提供了许多图形编程中常用的向量和矩阵类型。

类型 说明 示例
int / float / double / uint / bool 基础标量类型 float alpha = 1.0;
vec2 / vec3 / vec4 浮点向量类型 vec3 color = vec3(1.0, 0.0, 0.0);
ivec2 / uvec3 / bvec4 整数、无符号整数、布尔向量 ivec2 size = ivec2(800, 600);
mat3 / mat4 矩阵类型 mat4 model = mat4(1.0);
sampler2D 二维纹理采样器 uniform sampler2D uTexture;
gl_Position 顶点着色器内建输出变量 gl_Position = vec4(aPos, 1.0);
gl_FragCoord 片段着色器内建输入变量，表示当前片元坐标 float depth = gl_FragCoord.z;

补充两点：

  • 在现代 GLSL 中，通常不再直接使用 gl_FragColor，而是自己声明输出变量，例如 out vec4 FragColor;
  • vec4(aPos, 1.0) 是一种常见写法，表示把 vec3 扩展成齐次坐标

常用内建函数

GLSL 内置了大量图形计算函数，下面是学习阶段最常见的一些。

函数名 说明 示例
texture() 纹理采样 texture(uTexture, TexCoord).rgb
pow() 幂运算，常用于 Gamma 校正 pow(color, vec3(2.2))
max() 取较大值 max(dot(n, lightDir), 0.0)
min() 取较小值 min(a, b)
mix() 线性插值 / 混合 mix(colorA, colorB, 0.8)
dot() 点积，常用于光照计算 dot(normal, lightDir)
normalize() 单位化向量 normalize(normal)
fract() 取小数部分 fract(depth * 256.0)

其中 texture2D() 是旧写法，在现代 GLSL 中通常统一使用：

texture(uTexture, TexCoord)

vec4 packDepth(float depth)
{
    const vec4 bitShift = vec4(1.0, 256.0, 256.0 * 256.0, 256.0 * 256.0 * 256.0);
    const vec4 bitMask = vec4(1.0 / 256.0, 1.0 / 256.0, 1.0 / 256.0, 0.0);

    vec4 rgbaDepth = fract(depth * bitShift);
    rgbaDepth -= rgbaDepth.gbaa * bitMask;
    return rgbaDepth;
}

float unpackDepth(vec4 rgbaDepth)
{
    const vec4 bitShift = vec4(
        1.0,
        1.0 / 256.0,
        1.0 / (256.0 * 256.0),
        1.0 / (256.0 * 256.0 * 256.0)
    );

    return dot(rgbaDepth, bitShift);
}

如果在片段着色器中输出打包后的深度值，可以这样写：

4

6

out vec4 FragColor;

void main()
{
    FragColor = packDepth(gl_FragCoord.z);
}

这段代码的核心思路是：

  • 把一个 float 深度值拆分到 RGBA 四个通道中
  • 每个通道保存一部分精度
  • 之后再通过 unpackDepth() 还原近似的原始深度值

这种技巧常见于一些旧方案、兼容性方案，或者需要把深度以颜色形式存储的场景中。

小结

GLSL 是 OpenGL 可编程渲染管线的核心部分。入门阶段建议先掌握以下内容：

  • 理解顶点着色器和片段着色器的职责
  • 熟悉 in、out、uniform 等关键字
  • 掌握常用向量、矩阵和纹理采样类型
  • 学会阅读和编写最基础的着色器代码

后续继续学习光照、材质、阴影、后处理时，GLSL 会反复出现。越早熟悉它的语法和数据流，后面的 OpenGL 内容就越容易理解。
