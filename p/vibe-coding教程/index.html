初始化

1. setup-matt-pocock-skills

一次性初始化配置技能

在使用 Matt Pocock 系列工程技能之前，为当前仓库搭建好这些技能所依赖的基础配置。具体包括三个方面：

  1. 议题追踪器（Issue Tracker） — 确定当前项目的 issue 存放在哪里（GitHub Issues、GitLab Issues、本地 Markdown 文件如 .scratch/，或其他如 Jira/Linear），技能会自动探测并让用户确认。

  2. 分类标签词汇表（Triage Labels） — 如果安装了 triage 技能，则配置五个标准 triage 标签（needs-triage、needs-info、ready-for-agent、ready-for-human、wontfix），或让用户自定义已有标签名的映射。

  3. 领域文档布局（Domain Docs） — 确定 CONTEXT.md 和 ADR（架构决策记录）的存放位置。默认是单上下文（根目录放一份 CONTEXT.md + docs/adr/），仅在检测到 monorepo 信号时才提供多上下文选项。

最终产物是三个配置文件（放在 docs/agents/ 下）以及在 CLAUDE.md 或 AGENTS.md 中添加一个 ## Agent skills 区块，供 to-tickets、triage、to-spec 等其他技能读取使用。
